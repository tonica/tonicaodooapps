# Lens Memoria
Lens Memoria is an Odoo 19 Community module to manage photographic fonds.

Features (minimum):
- Model for Memory items with photo, metadata, and tagging.
- Categories and Tags for organizing memories.
- Basic views (list and form) to manage memories.

Installation:
- Place this folder inside your Odoo addons path.
- Update apps list and install Lens Memoria from the Apps dashboard.
